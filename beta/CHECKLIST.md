# 上線前冒煙測試清單（喵喵照護安心管家）

每次改動要部署前，照這份走一遍。分兩關：先跑自動測試，再手動點關鍵路徑。
全部 OK 才 `npm run deploy`。

---

## 關卡 0：自動測試（必過，不可跳）

```bash
cd beta && npm test
```

- [ ] 全部 pass（0 fail）。有 fail 就先修，別部署。
- 涵蓋：LINE 指令解析、每日摘要計算、網站/後端食物常數一致、HTML/JS 解析、關鍵畫面元素、回歸守門員。

---

## 關卡 1：手動關鍵路徑（30 秒，實機點過）

### LINE（用手機或 LINE 官方帳號自己測）
- [ ] 打「水 60」→ 出現喝水卡片，今日水分有加上去。
- [ ] 打「罐頭 30」→ 食物卡片、熱量有算（沒設公式會標估算/提醒）。
- [ ] 打「藥 早 已吃」→ 用藥卡片，今日目標「早」變 ✓。
- [ ] 打「改 24」→ 上一筆數量被改成 24。
- [ ] 打「今天」→ 今日總覽卡片正常（藥只顯示一次，不重複）。
- [ ] 同一則指令不會收到兩次回覆。

### 網站（點「喵喵照護站」進去）
- [ ] 今天分頁：今日喵喵狀況總覽、今日每筆紀錄、近日健康明細都載入。
- [ ] 月曆分頁：點任一天能看當天資料。
- [ ] 回顧分頁：須注意事件、飲食水分、趨勢圖都出得來。
- [ ] 「存成圖片給醫生」→ 幾秒內跳出報告圖，可長按存到相簿（沒有逾時/白畫面）。
- [ ] 設定 → 常吃的食物 → 編輯一個舊食物按儲存 → 重開確認資料沒被清掉。
- [ ] 新食物表單：名稱＋類型＋熱量三格就能存；水分比例在「進階設定」裡。

### 新手（用一般瀏覽器 Safari/Chrome）
- [ ] 開 `https://cat-care-beta.hannahchen6134.workers.dev/?tour=1` → 三步聚光燈導覽正常（歡迎 → 圈設定 → 圈＋新增）。

## 關卡 2：部署後快速確認

```bash
cd beta && npm run deploy
```

- [ ] 部署成功、有新的 Version ID。
- [ ] 打開網站首頁能正常載入（沒有整頁白掉）。
- [ ] 後台 `/admin/testers?key=...` 打得開、數字正常。

---

## Beta 期間（每天／出事時）

- [ ] 每天瞄一次 `/admin/testers`：留存、活躍、總筆數有沒有動。
- [ ] 有人回報怪事時，電腦開 `wrangler tail`（即時看 Worker log）一邊重現，找紅字例外。
- [ ] 使用者若收到「系統忙碌中，這筆沒記錄成功」= 後端有 throw，一定要追。
- [ ] 改資料庫前先備份 D1（可回滾）。

---

## 安全網

- 回滾：git 有 commit、Cloudflare 有版本 ID，可退回上一版。
- 緊急關人：後台 `/admin/testers` 一鍵停用某測試者。
- 開發告一段落後：到 Cloudflare 後台撤銷本機用的 API 權杖。
