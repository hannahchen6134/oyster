# 資料保存與帶走政策（尚未啟用期限管理）

確認方向：持續使用期間保存累積照護紀錄。一年未使用後先通知，提供 90 天下載或重新啟用；重新使用則取消待清除狀態。

目前已實作：單貓 CSV；經登入驗證的爸媽帳戶 JSON 匯出，含未刪除貓咪、紀錄、用藥、獸醫、看診、檢驗、每日彙整、任務及照護範本。不包含登入憑證、分享權杖、系統診斷。JSON 不是自動還原功能。

尚未實作／不得對外宣稱已完成：
- 以實際紀錄、查看、下載更新的帳戶最後使用時間。
- 一年未使用的通知、通知送達失敗處理、90 天寬限與重新啟用。
- 期限屆滿清除、備份保留／清除規則與還原演練。

本次不清除任何既有客戶資料，不寄送保存期限通知。不可用 users.updatedAt 作為未使用判準，也不可將舊帳戶在部署當天直接判定可刪除。

對外發布前須驗證上述程序；保存期是產品承諾，不是資料庫備份還原窗口。
