# 組合快捷

主食＋水、副食＋水只預填類別文字（含結尾空格），沒有數字按鈕或預設份量。
輸入「主食＋水 31 5」代表主食31g、水5ml。副食同理，小數可用。缺數字或多填數字不寫入部分紀錄。
卡片內快捷帶原貓名，原生快捷沿用目前選貓。點快捷仍不會直接建立紀錄。

預設主食＋水靠前、副食＋水在更多紀錄之前。個人近30天有效紀錄每天更新排序，最多查各貓200筆，再取最近200筆。同一貓同一訊息的食物與水計為一次組合，只有點擊不計次。延用既有家庭及記錄者隔離；更新在回覆後執行。

照護補問卡附常用快捷；點日常快捷退出補填流程，既有範本不變。LINE未送出的輸入框不支援追加，所以應點組合一次、填兩個數字送出，不連點兩個預填按鈕。
