# 組合快捷

主食＋水、副食＋水在輸入框預填「主食0水0／副食0水0」，沒有數字按鈕。0是待修改的佔位數量，點擊不送出。
將0改成實際數量，例如「主食31水5」代表主食31g、水5ml。副食同理，小數可用。未修改的全0範本不建立紀錄；舊版組合語法仍保留相容。
卡片內快捷帶原貓名，原生快捷也帶入已選貓名，尚未選貓時不猜測對象。點快捷仍不會直接建立紀錄。

預設主食＋水靠前、副食＋水在更多紀錄之前。個人近30天有效紀錄每天更新排序，最多查各貓200筆，再取最近200筆。同一貓同一訊息的食物與水計為一次組合，只有點擊不計次。延用既有家庭及記錄者隔離；更新在回覆後執行。

照護補問卡附常用快捷；點日常快捷退出補填流程，既有範本不變。LINE未送出的輸入框不支援追加，所以應點組合一次、修改兩個0後送出，不連點兩個預填按鈕。
