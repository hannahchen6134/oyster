# 說明・怎麼記更新

## 核對結果

- 摘要、出摘要、出報告是同一個選貓／用途入口，正式選單為「出摘要」。沒有獨立的另一種 AI 摘要。
- 近七天記錄：每日水分／熱量紀錄與日均回顧；出摘要：給醫生看或給照護者的圖片與 QR Code。
- 常用快捷預設主食、乾乾、零食、水、藥、尿尿、便便、更多紀錄；會依使用者有效紀錄調整。更多紀錄另有體重、嘔吐、精神、保健、備註。
- 記一筆、完成紀錄的卡片可繼續使用快捷。主食等填入輸入框，使用者補數量／情況後送出；尿尿／便便先選狀況。
- 醫生摘要沿用原 A4 回診摘要（近 14 天趨勢、飲食水分組成、注意事項、每日明細）；照護摘要用既存範本，缺餵食／餵藥／相處資料才逐項詢問。
- 管家後台沿用 LIFF 入口，不保證免登入。

## 舊版過期或不適合第一層的內容

三張「常用／進階記法／進階功能」未介紹常用快捷、出摘要圖片與 QR；把品牌設定、修正、邀請、電腦登入擠在新手第一層；「免登入」承諾不精確。這些進階記法保留在完整記法，第一層不再展開。舊教學所列功能不全是失效功能，主要問題是入口與重點落後。

「剛剛吐白沫」未通過 parser，因此不採用；改用已通過的「嘔吐 白沫」。

## 驗證界線

以本地資料庫與模擬 LINE 傳送測試所有文字入口，LINE 官方 validate API 驗證 Flex 格式（不向客戶傳測試訊息）。沒有操作實體手機，不能宣稱實機點擊通過。20～30 秒為快速掃讀目標，非真人計時測試。


範例卡緊湊版：主標 19px、分類與例句 16px、頁碼 14px；分類間距 12px、例句間距 6px、框內距 10px。例句改為一般字重，保留分類粗體。

完整記法入口現改為分類選單；選單 message action 為「記法：分類名稱」，只回覆該類；「其他記法」回到完整記法選單。原有詳細教學保留，不再整份展開。文字備援同樣只顯示選中分類。
