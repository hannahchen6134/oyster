# 付費方案設計（v2，已含 LINE 推播成本試算）

## 成本結構（關鍵認知）
- 客戶傳訊息、機器人「回覆」：**免費**，不限量（回診摘要、今日確認、記錄全是回覆）
- 要錢的只有「主動推播」：每晚照護提醒、回診前提醒
- 免費額度 200 則/月；輕用量 NT$800/月（5,000 則，約每則 NT$0.16）
- 一隻開滿提醒的貓 ≈ 30 則/月 ≈ NT$5/月成本
- 程式已做「以飼主為單位合併推播」：多貓＋回診提醒同晚只算 1 則

定價話術：「一個月一罐好罐頭的錢，換全年安心」。

## 呈現原則
1. Beta 期間全功能免費，但 Plus 功能掛「Plus」小標籤（先建立認知，正式收費是「優惠結束」不是「功能被拿走」）
2. 免費用戶點 Plus 功能 → 溫柔的介紹卡（說明功能價值＋了解 Plus 按鈕），不是錯誤訊息
3. 設定頁「方案與功能」入口放對照表
4. 到期永不刪資料，只收起 Plus 功能
