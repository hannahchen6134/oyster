# 喵喵照護安心管家 — 喵爸媽安心上手

讓每一次紀錄，都是對貓貓的守護。
在 LINE 直接打字就能記，照護站（網站）負責看整體與修改。
這份說明也是圖文選單「安心上手」按鈕（傳送「安心上手」）的完整版。

---

## 一、第一次使用

| 步驟 | 輸入 | 結果 |
| --- | --- | --- |
| 1 | `新增貓咪 蚵仔` | 建立貓咪檔案 |
| 2 | `水 20` | 記第一筆，馬上回今日確認 |
| 3 | `照護站` | 拿到照護站專屬連結（會自動延長效期） |

到照護站「設定 → 食物」把常吃的食物建好（每克熱量、水分比例），
之後在 LINE 打「乾糧 希爾斯 4g」就會自動算熱量和水分。

> 連結過期了怎麼辦？回 LINE 輸入「照護站」就能拿到新連結，
> **既有的照護資料都不會消失**。

## 二、日常記錄

平常怎麼說話就怎麼記，例如「喝了20」「吃了罐頭 30」也看得懂。

### 喝水
```
水 20          ← 20 ml，「水20」不加空格也可以
```

### 食物（乾糧/罐頭/濕食/零食）
```
乾糧 希爾斯 4g
罐頭 皇家 30g
濕食 20
零食 5
```
品名要跟照護站「設定 → 食物」的顯示名稱一樣，才會自動算熱量水分；
沒設定過的品項也會照樣記下來，只是不算熱量。

### 餵藥
```
藥 已吃            ← 最簡單，記一筆「藥・已吃」
藥 早 已吃         ← 加時段：早/中午/晚
藥 心臟藥 晚 已吃   ← 加藥名+時段
藥 心臟藥 晚 沒餵到 ← 狀態：已吃/沒餵到/吐掉/拒吃
```
狀態一共四種：**已吃、沒餵到、吐掉、拒吃**。
沒餵到/吐掉/拒吃會標成「留意」，月曆和回診摘要會幫你留意。

### 身體狀況
```
吐 白色泡沫
便 成形偏軟        （「軟便」兩個字也可以）
精神 活動力差
備註 今天有梳毛
```

### 記錯了想改（改最近一筆）
```
改 54        ← 把最近一筆的數字改成 54
剩 20        ← 沒吃完/沒喝完，扣掉剩下的量
刪除         ← 刪掉最近一筆
```

### 補登（忘記記的時候）
```
昨天 21:30 水 20    ← 記到昨天 21:30
前天 乾糧 4g        ← 記到前天
```

## 三、查詢

| 輸入 | 看到什麼 |
| --- | --- |
| `紀錄` | 快速紀錄選單（不知道怎麼打字時按這個） |
| `今天` | 今日照護確認 |
| `回診摘要` | 近 7 天摘要卡＋完整版在照護站「回診」頁 |
| `月曆` | 本月統計摘要 |
| `照護站` | 照護站專屬連結 |
| `安心上手` | 上手小抄 |

## 四、多隻貓咪

訊息開頭加貓咪名字就能指定：
```
蚵仔 水 20
小虎 藥 已吃
蚵仔            ← 只打名字，看該貓咪今日確認
```

## 五、每日目標與照護提醒

- **設定 → 每日目標**：填水分/熱量目標、勾每天要餵的藥時段。
  之後每次記錄，LINE 下方會顯示還差多少，全達成有一句鼓勵。
- **設定 → 提醒**：勾選想被提醒的狀況（藥還沒紀錄、喝水量下降、食慾下降、連續兩天沒便便）。
  每晚 21:00 檢查一次，有需要才會輕輕提醒；一切平穩就不打擾。

## 六、照護站（網站）能做的事

- **今天**：今日照護確認板、一鍵複製「今日交接卡」給家人朋友、每筆紀錄的編輯/刪除、補登
- **月曆**：每天的水分熱量、用藥、留意標記、回診日；點日期進當日明細
- **回診**：近 7 天摘要一鍵「複製給醫生」、給醫生的一句話、看診紀錄、血檢紀錄與近 30 天趨勢
- **設定**：喵爸媽安心上手、貓咪資料、食物公式、藥物清單、醫院醫生、回診資料、血檢、每日目標、提醒

修改或刪除任何一筆紀錄，當日摘要都會立刻重新整理，不用擔心數字對不上。
