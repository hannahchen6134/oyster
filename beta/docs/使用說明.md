# 貓貓照護管家 — 使用說明

在 LINE 直接打字就能記錄,照護站(網站)負責看整體與修改。
這份說明也是圖文選單「使用說明」按鈕(傳送「說明」)的完整版。

---

## 一、第一次使用

| 步驟 | 輸入 | 結果 |
| --- | --- | --- |
| 1 | `新增貓咪 蚵仔` | 建立貓咪檔案 |
| 2 | `水 20` | 記第一筆,馬上回今日累積 |
| 3 | `網站` | 拿到照護站登入連結(自動延長效期) |

到照護站「設定 → 食物」把常吃的食物建好(每克熱量、水分比例),
之後在 LINE 打「乾糧 希爾斯 4g」就會自動算熱量和水分。

---

## 二、日常記錄指令

### 喝水
```
水 20          ← 20 ml,「水20」不加空格也可以
```

### 食物(乾糧/罐頭/濕食/零食)
```
乾糧 希爾斯 4g
罐頭 皇家 30g
濕食 20
零食 5
```
品名要跟照護站「設定 → 食物」的顯示名稱一樣,才會自動算熱量水分;
沒設定過的品項也會照樣記下來,只是不算熱量。

### 餵藥(你問的這個!)
```
藥 已吃            ← 最簡單,記一筆「藥・已吃」
藥 早 已吃         ← 加時段:早/中午/晚
藥 心臟藥 晚 已吃   ← 加藥名+時段
藥 心臟藥 晚 漏餵   ← 狀態:已吃/漏餵/吐掉/拒吃
```
狀態一共四種:**已吃、漏餵、吐掉、拒吃**。
漏餵/吐掉/拒吃會被標成異常,月曆和近 7 天會提醒你。

### 身體狀況
```
吐 白色泡沫
便 成形偏軟        （「軟便」兩個字也可以）
精神 活動力差
備註 今天有梳毛
```

### 補登(忘記記的時候)
```
昨天 21:30 水 20    ← 記到昨天 21:30
前天 乾糧 4g        ← 記到前天
```

## 三、查詢指令

| 輸入 | 看到什麼 |
| --- | --- |
| `今天` | 今日累積總結 |
| `近7天` | 一週的水分/熱量/用藥一覽 |
| `月曆` | 本月統計摘要 |
| `回診` | 下次回診時間、醫院醫生、醫囑 |
| `網站` | 照護站登入連結 |
| `說明` | 指令小抄 |

## 四、多隻貓咪

訊息開頭加貓咪名字就能指定:
```
蚵仔 水 20
小虎 藥 已吃
蚵仔            ← 只打名字,看該貓咪今日總結
```

## 五、每日目標與照護提醒

- **設定 → 每日目標**:填水分/熱量目標、勾每天要餵的藥時段。
  之後每次記錄,LINE 總結下方會顯示「還差多少」,全達成有鼓勵語。
- **設定 → 提醒**:勾選想被提醒的狀況(藥沒記錄、喝水量下降、食慾下降、連續兩天沒便便)。
  每晚 21:00 檢查一次,有需要才會傳 LINE;一切正常就不打擾。

## 六、照護站(網站)能做的事

- **每日明細**:五張總結卡、給醫生的一句話(一鍵複製)、當日每筆紀錄的編輯/刪除、補登、記錄看診(醫院/醫生/時間)
- **月曆**:每天的水分熱量、用藥、異常標記、回診日;點日期進當日明細
- **近 30 天**:水分與熱量趨勢圖+每日總覽表
- **設定**:貓咪資料、食物公式、藥物清單、醫院醫生、回診資料

修改或刪除任何一筆紀錄,當日總結都會立刻重算,不用擔心數字對不上。

---

※ 本服務僅協助記錄與整理,不提供醫療診斷;貓咪健康問題請諮詢獸醫師。
