# 摘要日期選擇

醫生：選貓 → 給醫生看 → 7／14／21／30 天或自訂日期 → 原 A4 摘要圖片＋QR。
初次預設 30 天，使用既有 app_kv 記住各家庭各貓的上次選擇。預設天數以當天回推；自訂日期保留原起訖並提供「上次自訂期間」，不擅自更動日期。

照護：選貓 → 給照護者 → 選開始、結束日期 → 已存安排／補缺項 → 圖片＋QR。
選定日期顯示在照護摘要頂部，近期紀錄仍取實際近 14 天，不用未來照護日期推測餵食或用藥。

自訂日期使用 LINE 原生日曆；開始日不可晚於結束日，最多 90 天，醫生回顧不可晚於今天，照護可選未來日期。包含起訖兩天。QR 連結有效期限維持 7 天，與摘要內容期間分開。

A4 共用資料由 31 天擴為 90 天，所有趨勢與明細使用同一日期窗口；沒有紀錄的日期保留空值，明細標「未記錄」。沿用既有分頁，不縮小字體。網頁出摘要新增 21 天按鈕；LINE 與 QR 公開頁共用 A4 產圖資料及排版。

未改資料庫 schema、未新增 AI 判斷。以測試資料檢查跨月、記憶隔離、錯誤日期、長期間、重複點擊與既有照護補填。沒有操作實體 LINE 手機。
