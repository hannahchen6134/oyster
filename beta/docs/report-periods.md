# LINE 摘要期間

醫生與照護者共用：選貓 → 選用途 → 往前 14 天／往前一個月（30 天）。含今天，由系統自動計算，不要求選起訖日。
舊卡片的自訂日期、上次自訂期間與日期選擇事件，一律返回兩個期間選項。

醫生沿用原 A4 摘要圖片。照護者沿用已儲存安排，只有必要照護說明不足時才補問。兩者的近期紀錄均依所選14或30天查詢；回顧期間不寫進本次照護安排日期。

完成直接傳送圖片與 QR，並提供「查看詳細資料」LIFF 後台按鈕。QR 分享期限仍為7天，與資料回顧期間分開。未改網頁自訂範圍與共用A4長期間支援。

驗證：兩種用途的固定選項、舊日期入口回復、日期範圍、圖片與QR、詳細資料按鈕及既有資料隔離與重複點擊測試。未操作實體LINE手機。
