# 日常操作減法

- 單筆紀錄與卡片改數量完成：顯示貓名、內容、時間、必要熱量提醒，不再每次展開今日累積及目標。保留改數量、刪除、常用快捷與看紀錄；熱量未設定或粗估時保留設定入口。
- 常用快捷仍按個人有效紀錄排序，維持既有每日穩定策略。卡內清楚標示繼續記給哪隻貓，點舊卡仍帶入該卡貓名。
- 看紀錄：今天／近七天／吃過的食物，完整資料可進後台。不再把三個按鈕都導向今天。
- 使用說明、說明、安心上手、第一次使用都進同一張新手卡；範例與進階分類留在內層，舊文字指令繼續支援。
- 測試連續主食、水、藥、從卡片修改水量再繼續記、切換貓後重用舊卡。資料庫與LINE傳送採測試替身；沒有操作實際客戶手機。
- 六格選單圖本輪維持現況，先改善每日流程，不一次重做所有介面。
