## 1. 圖文選單（Phase 8）

設計稿與素材已完成，在 `beta/richmenu/`：

- `richmenu.png` — 2500×1686 成品圖（與照護站同一套視覺：米白紙感 + 墨綠）
- `richmenu.html` — 設計稿原始檔，改字改色後重新截圖即可
- `create-rich-menu.mjs` — 一鍵上架腳本（建立選單 → 上傳圖 → 設為預設）

### 編排邏輯（2×3）

| | | |
| --- | --- | --- |
| 今日總結（今天） | 月曆（月曆） | 近 7 天（近7天） |
| 回診資訊（回診） | **開啟照護站（網站）** ← 主行動，反白強調 | 使用說明（說明） |

- 上排＝「看數據」：使用頻率最高的三個查詢，由左至右依使用頻率排。
- 下排＝「行動」：中間放最重要的入口「照護站」，用品牌綠底反白突顯；
  兩側是回診與說明這類低頻但需要時很重要的功能。
- 每格都標注會傳送的指令文字，順便教育使用者「原來打字也可以」。
- 「記錄」不放選單：記錄靠直接打字最快（水 20），選單教育成本反而高，由「使用說明」承接。

### 上架方式

```bash
export LINE_CHANNEL_ACCESS_TOKEN=（Beta channel 的 token）
cd beta && node richmenu/create-rich-menu.mjs richmenu/richmenu.png
```

## 2. 付費功能分層

原則：**記錄本身永遠免費**。記錄習慣是產品的命脈，任何擋在「記錄」前面的付費牆都會殺死留存；
要收費的是「多人協作」「對外分享」「主動提醒」「資料帶走」——這些不是天天用，
但需要時價值極高，而且（推播、匯出）有實際成本。

### 免費版（記錄核心）

- 1 隻貓咪
- LINE 快速記錄全部指令（水／食物／藥／吐／便／精神／補登）
- 今天、近 7 天、月曆、回診查詢
- 照護站：每日明細（含編輯刪除）、月曆、近 30 天、全部設定
- 給醫生的一句話

### 照護家（Pro）— 建議 NT$99／月或 NT$990／年

1. **共同照護**（`care_members` 表已建）：邀請家人、伴侶、貓保母加入同一隻貓，
   大家都能用自己的 LINE 記錄與查看。→ 這是你提到的「加朋友一起看數據」，最強的付費理由，
   因為多人家庭是照護紀錄最痛的場景（誰餵過藥？）。
2. **醫生分享連結**（`share_links` 表已建）：產生 30 天唯讀報告連結傳給獸醫，回診前醫生先看。
3. **多貓**：第 2 隻起需要 Pro（多貓家庭通常是重度使用者，付費意願高）。
4. **回診與餵藥提醒**：LINE 推播「明天 14:30 回診」「晚上的藥還沒記錄」。
   推播是 LINE 收費資源，天然適合放付費版。
5. **資料匯出**：CSV 全量匯出＋回診用 PDF 報告。
6. **完整歷史**：免費版看近 90 天，Pro 不限（軟性限制，資料都留著，升級即解鎖）。

### 定價備註

- Beta 期間全部免費，累積 3–5 位試用者的回饋再開收費。
- 先做 1、2（資料表都建好了），3–6 視回饋排序。
- 上線時給 Beta 試用者永久折扣或 3 個月 Pro，感謝早期支持。

## 3. UIUX 建議（設計師視角）

本次已完成的：置中 880px 版心、襯線標題＋無襯線內文的雙字體層次、降低字重（900→600/700）、
拿掉漸層與圓球背景改用細線與紙感、表格數字用等寬數字對齊、登入頁垂直置中、
分頁改為底線式導覽、清單改為細線分隔取代卡片套卡片。

之後值得做的（依投資報酬排序）：

1. **記錄後的即時回饋**：新增紀錄後，統計卡數字做 200ms 的變化動畫，讓「記了有感」。
2. **今日空狀態引導**：沒有紀錄時，除了文字，放 2–3 顆快速鍵（＋喝水、＋乾糧、＋藥），
   點了直接開表單並預選類別，降低第一筆的門檻。
3. **月曆格子的資訊密度**：目前水分/熱量兩行在小螢幕略擠，可改成單一「達標點」
  （當日水分達目標＝實心點，未達＝空心點），點進去才看細節；目標值在貓咪設定裡填。
4. **趨勢頁圖表化**：近 30 天表格保留，上方加一條水分 + 熱量的 30 天折線（SVG 即可不用套件），
   醫生一眼看趨勢比逐列讀數字快十倍。
5. **設定的層級**：醫院醫生、回診其實是「醫療」，食物藥物是「日常」，之後項目變多可以分兩組。
6. **鍵盤與焦點**：modal 開啟時自動 focus 第一個欄位、Esc 關閉、Enter 儲存。
7. **PWA**：加 manifest 讓照護站可以「加到主畫面」，圖示用貓掌，開啟速度感受會完全不同。

## 4. 金流怎麼接（台灣、個人開發者）

結論：**Beta 不收費；正式版第一步用綠界（ECPay）信用卡定期定額，量大再加 LINE Pay。**

| 方案 | 個人可申請 | 定期定額 | 手續費 | 備註 |
| --- | --- | --- | --- | --- |
| 綠界 ECPay | ✅（個人會員） | ✅ 信用卡定期定額 | ~2.75% | 台灣訂閱制個人開發者的主流選擇 |
| LINE Pay | ❌ 需公司／行號 | ✅ | ~3% | 與 LINE 生態最順，成立行號後再上 |
| Stripe | ❌ 台灣需公司主體 | ✅ | 2.9%+ | 面向海外市場才考慮 |
| Portaly／訂閱連結 | ✅ | ✅ | ~5–10% | 零開發量，適合最早期手動開通 |

### 建議的接法（綠界定期定額）

1. 照護站「設定」加一個「方案」頁：顯示目前方案＋「升級照護家」按鈕。
2. 按鈕導向 Worker 的 `/api/checkout`：產生綠界定期定額訂單（帶 lineUserId 進 `CustomField`），302 到綠界付款頁。
3. 綠界每期扣款後打 `ReturnURL`（Worker 新增 `/api/ecpay/notify`）：驗證 CheckMacValue
   → 在 `users` 表寫入 `plan='pro'`、`planExpiresAt`。
4. 扣款失敗或取消：到期後自動降回免費版（軟降級，資料不刪）。
5. LINE 端輸入「方案」可查目前狀態＋升級連結。

最早期（前 10 個付費使用者）甚至可以更簡單：Portaly 訂閱連結 + 你手動在資料庫開通，
先驗證「有人願意付」再寫金流串接。
